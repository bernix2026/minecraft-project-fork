## About

Minecraft Hub is an educational resource website designed to help Minecraft players of all skill levels. The platform provides statistical information about the game, interesting facts, advanced building techniques, and step-by-step tutorials for beginners.

**Note:** This project is created for educational purposes and is not affiliated with Mojang AB or Microsoft Corporation.

## Features

- **Statistics Page**: Shows key Minecraft metrics including active players, platform support, language support, and total time played
- **Interesting Facts**: Curated collection of fascinating Minecraft facts about world generation, redstone mechanics, and hidden game features
- **Cool Builds**: Advanced building techniques and architectural secrets for experienced players
- **Beginner Tutorials**: Step-by-step guides covering essential Minecraft survival and gameplay mechanics

## Usage

1. Open `index.html` in any modern web browser
2. Navigate through the site using the sticky header navigation
3. Click on "Read More" buttons to view full tutorial content
4. Use the "Back to [Section]" buttons to return to the main index

## Installation

### Local Installation

1. Clone or download this repository
2. Extract files if downloaded as a ZIP
3. Open `index.html` in your preferred web browser
4. No server setup or build process required - works as static HTML files

### Requirements

- Any modern web browser (Chrome, Firefox, Edge, Safari)
- No external dependencies required
- Works offline once files are downloaded
